How it works

One engine, four layers, and every step measured.

Scora reads the market from the top down — the long cycle, the regime, the sectors, and only then individual stocks. Each layer has one job, and each one is tested before it's allowed to move money.

The four layers

Higher layers set limits for the ones below. A stock idea never overrides the regime.

The breadth loop

A system that checks its own read.

The top-down view is compared every day with how many stocks are actually participating. When they disagree — say, the index sits above its 200-day average while fewer than 45% of names do — Scora flags the divergence. It's an early warning, not a forecast.

The AI layer

Explains the numbers. Never invents them.

AI writes the commentary — theses, research notes, red-flag scans. A gate in code then checks every figure it emitted against the data it was given, and logs the run with its sources. Governance doesn't depend on the model being well-behaved.

  1. 1
    Grounded input
    The model only sees verified data for that ticker or regime.
  2. 2
    Figure check in code
    Every number in the answer is matched against its source.
  3. 3
    Flag and log
    Unverified figures are flagged; every run lands in your audit trail.
